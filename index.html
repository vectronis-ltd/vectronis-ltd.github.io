Services

How a project runs

Discovery

A short call and a written brief: what the system must do, for whom, and what success looks like.

Proposal

Scope, timeline and a fixed price or clear rate, agreed before any code is written.

Build

Work in short cycles with something you can try every one or two weeks, so direction can change early.

Release and support

Launch, handover with documentation, and ongoing support if you want it.
